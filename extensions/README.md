# Extensions

This directory contains optional SRP extensions that extend the platform's capabilities.

Extensions can add:
- Custom search providers
- Additional analysis tools
- UI widgets
- Custom tool integrations

## Structure

Each extension should be in its own directory with:
- `manifest.json` — Extension metadata
- `src/` — Extension source code
- `README.md` — Usage documentation

## Extension Types

| Type | Description |
|------|-------------|
| `search` | Web research and documentation providers |
| `analysis` | Static/dynamic analysis integrations |
| `tool` | External tool runners |
| `ui` | Web UI widgets and panels |
