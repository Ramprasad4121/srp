# Security policy

Report vulnerabilities in SRP itself privately through GitHub: Security tab -> "Report a vulnerability" on https://github.com/Ramprasad4121/srp. Please do not open public issues for security bugs.

Scope: the API server, CLI, MCP server, and analysis core in this repository. Findings SRP reports about *your* contracts are not SRP vulnerabilities; false positives and false negatives are welcome as normal issues with a minimal fixture.

Supported versions: the latest `main`.
